CP-300

connecting…
Click the screen and type: the keys go to the CP-300. Esc = BREAK, Backspace = left arrow.

Disk drives — drop a .dsk / .dmk / .hfe / .jv1 / .jv3 file on a drive

FreHD hard disk — the files of the FreHD's SD card (FREHD.ROM, hard disk images); mount an image as hard disk 0 or 1

An image mounted here is hard disk 0 or 1 of the CP-300. The FreHD ROM's own menu mounts the same files.

CP-400 hard disk (MiniIDE) — a raw image of 512 byte sectors, any size (a few hundred MB take a while; the file is used in place)

IDE disk empty
Needs the cartridge ROM above (the DOS). The disk is used in place: the CP-400's writes go straight to the file on the board.

CP-400 floppy drives — drop a CoCo .dsk or .jvc image (35 or 40 tracks, 18 sectors of 256 bytes) on a drive

Needs a Disk BASIC ROM as the cartridge (8 KB, for example Disk BASIC 1.1 or an HDB-DOS image). With a floppy image mounted the controller card is there; without one the CP-400 sees no floppy hardware (the MiniIDE disk is unaffected).

MSX disk interface (slot 2) — drop a raw .dsk image (720 KB, 360 KB, 640 KB or 320 KB) on a drive

Needs the disk interface ROM below (16 KB, "National" type: the Gradiente Expert DD Plus ROM works). The drives are used as an MSX-DOS disk; FORMAT is not supported (no WRITE TRACK): use formatted images.

Cassette — .tap (ZX Spectrum), .cas (MSX, CoCo, MC-10, CP-300, by the machine selected), .c10 / .k7, .wav

Tape empty
The tape runs while Play is on and the computer's motor is on (MSX, CP-400); on the other machines press Play when the computer asks for it.
